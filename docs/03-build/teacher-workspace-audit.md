# 선생님 작업 공간 점검 및 수정

2026-11-11 기준. 프런트엔드 변경은 로컬 작업이며 Git push 및 배포는 수행하지 않았다.

## 확인한 문제와 수정

- `/teacher`와 `/teacher/home` 진입을 로그인 상태에 맞게 정리했다. 선생님은 대시보드와 공통 내비게이션을 사용하고 비로그인 방문자는 소개 화면을 본다. 홈과 내부 화면은 인증을 요구한다.
- 대시보드의 임의 통계, 가상 할 일, 테스트 승인, 동작하지 않는 PDF·QR·검색 기능을 제거했다. 실제 프로필, 공개 경력, 대표 작업, 자료, 한국 시간 기준 오늘의 수업을 표시한다.
- 개인페이지를 중심으로 소개·경력·대표 작업 편집 및 공개 미리보기 동선을 배치했다. 공통 색상·카드·간격을 적용하고 모바일 화면에서 줄바꿈과 버튼 배치를 확인했다.
- 각 데이터 요청의 실패를 별도로 표시하고 재시도를 제공한다. 승인 조회 실패를 승인 또는 빈 데이터로 취급하지 않는다.
- 수업 개설의 모든 하위 단계와 DB에서 승인 상태를 검사한다. 로컬 저장소를 통한 데모 승인 우회를 제거했다.
- 수업 언어·지원 언어·이미지·영상 필드가 실제 DB와 맞지 않는 문제를 수정했다.
- 회차별 온라인 수업 링크를 실제 저장·삭제·열기 기능으로 연결했다. 회차 테이블의 직접 수정 권한이 없어, 소유권과 URL을 검증하는 전용 RPC를 추가했다.
- 채팅의 가상 온라인·통화 상태와 동작하지 않는 부가 버튼, 자료실의 가상 유료 저장공간 안내를 제거했다. 자료 검색 및 로딩 실패 안내를 추가하고 메타데이터 저장 실패 시 업로드 파일을 정리한다.

## DB 적용

- `0027_teacher_workspace_integrity.sql`: 누락 필드, 승인 검사, 수업 생성 RPC 및 직접 삽입 방어. 연결된 Supabase DB에 적용했다.
- `0028_teacher_meeting_link.sql`: 본인 회차의 수업 링크만 수정하는 RPC. 연결된 Supabase DB에 적용했다.

## 검증

- 프로덕션 빌드 성공. 기존 이미지·폰트·훅 관련 lint 경고는 남아 있다.
- 인증·포트폴리오·대시보드 자동 테스트 16개 통과.
- 실제 컴포넌트와 격리된 데이터로 390px 및 1440px 브라우저 검증: 저장·수정·새로고침·공개 범위·삭제·오류 복구, 대시보드 이동 대상과 승인 오류 분리, 수업 링크 저장·삭제 통과.
- DB 롤백 테스트: 미승인 수업 생성 및 직접 삽입 차단, 승인 후 필드 저장, 본인 회차 링크 저장·삭제, 존재하지 않는 회차 변경 및 잘못된 URL 차단 통과. 테스트 데이터는 롤백했다.
- 비로그인 내부 경로가 로그인 화면으로 이동하고 `/teacher` 소개 화면은 공개되는 것을 확인했다.

브라우저 검증은 실제 사용자 계정으로 운영 사이트를 이용하는 종단 간 테스트가 아니다. 배포 후 실제 계정으로 로그인·내비게이션·저장 흐름을 확인하는 검증은 별도로 남아 있다. 외부 채용 연동, PDF 출력, QR 생성 기능은 이번 수정에 포함하지 않았다.

## 후속 수정: 선생님 진입 시 학생 홈으로 이동하는 문제

랜딩의 대시보드 링크가 학생 세션에서는 `/student/home`을 가리켰고, 서버의 역할 검사도 선생님 내부 경로를 학생 홈으로 변경했다. 기존 테스트 역시 이 잘못된 이동을 정상으로 간주했다.

대시보드 링크는 `/teacher/home`으로 고정했다. 서버는 비로그인 사용자를 선생님 로그인으로, 학생 세션은 역할 안내가 표시되는 선생님 로그인으로 연결한다. 프로필 조회 실패 시에도 선생님 진입 목적지를 유지한다. 로그인 안내에 계정 생성 동선을 제공하고, 선생님 계정으로 로그인하면 대시보드로 이동한다. 역할과 세션은 임의로 변경하지 않는다.

랜딩 렌더링, 미들웨어, 로그인 복귀 테스트를 보강했다. 비로그인·학생·선생님 및 프로필 조회 실패, 계정 전환 후 남아 있는 역할 오류 URL을 포함한다. 이 수정은 계정 데이터 변경이 필요하지 않다.

## 후속 수정: 가입 → 로그인 → 신청 → 승인 → 대시보드

- 신규 선생님 가입은 `not_applied`로 시작한다. 기존 심사 중·승인 계정은 그대로 유지한다.
- `/teacher/apply`에서 소개 작성, 최초 신청, 심사 대기, 보완 후 재신청, 승인 후 대시보드 진입을 제공한다. 소개 편집 후 신청 화면으로 복귀한다.
- 신청 시 DB에서 이름·한 줄 소개·자기소개·전문 분야와 최신 버전을 검사한다. 신청 전 계정을 곧바로 승인하는 변경은 차단한다.
- 미승인 계정의 선생님 내부 경로는 신청 화면으로 안내한다. 신청 및 소개 편집 경로는 이용 가능하며, 승인 조회 실패 시에도 대시보드를 열지 않는다.
- 랜딩의 중복 대시보드 버튼을 정리하고 가입·시작하기 중심으로 문구를 변경했다. 신청 화면은 승인 후에만 대시보드 진입 버튼을 표시한다.
- `0029_teacher_application_entry.sql`을 연결 DB에 적용했다. 실제 DB의 신규 가입·미완성 신청 차단·신청·중복 버전 차단·승인 조회 테스트를 롤백으로 검증했다.
- 자동 테스트 17개, 390px·1440px 신청 화면 브라우저 검증, 프로덕션 빌드를 통과했다. 브라우저는 격리 데이터 기반이며 운영 계정 종단 간 검증은 포함하지 않는다.
